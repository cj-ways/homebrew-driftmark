# homebrew-driftmark

Homebrew tap for [driftmark](https://github.com/cj-ways/driftmark): see what your AI agents changed in your Markdown docs, ranked by what each change means.

```
brew install cj-ways/driftmark/driftmark
```

The formula is written by `scripts/update-tap.sh` in the driftmark repo after each release; edits here are overwritten.
